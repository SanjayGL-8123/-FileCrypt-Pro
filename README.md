# 🔐 FileCrypt Pro – Web File Encryption Tool

A modern, high-performance web application that encrypts and decrypts files with a password. Works **offline and online**, powered by your choice of **Node.js, Python, cross-platform C, or 100% in-browser WebCrypto API**.

## 🚀 Quick Start (Windows, macOS & Linux)

You can run FileCrypt using any environment you have installed — **no C compiler required!**

### Option 1: Node.js (Fastest on Windows / Mac / Linux)
```bash
node server.js
```
Open **[http://127.0.0.1:8080](http://127.0.0.1:8080)** in your browser.

### Option 2: Python (Zero installation)
```bash
python server.py
```
Open **[http://127.0.0.1:8080](http://127.0.0.1:8080)** in your browser.

### Option 3: Double-Click Launcher (Windows)
Double-click **`start.bat`**. It will automatically detect Node.js or Python and open your browser!

### Option 4: Pure In-Browser (No server needed)
Open `public/index.html` directly in any modern browser. The built-in **WebCrypto engine** runs 100% client-side with zero data leaving your machine.

## 🛠️ Building the C Back End (Optional)

If you have a C compiler installed, you can compile `server.c`:

### On Windows (GCC / MinGW):
```cmd
gcc -Wall -Wextra -O2 -o filecrypt-server.exe server.c -lws2_32
filecrypt-server.exe
```

### On Windows (MSVC Developer Command Prompt):
```cmd
cl /O2 /Fe:filecrypt-server.exe server.c ws2_32.lib
filecrypt-server.exe
```

### On Linux or macOS:
```bash
gcc -Wall -Wextra -O2 -o filecrypt-server server.c
./filecrypt-server
```

## ✨ Features

- **Multi-Engine Execution**: Run via local C socket server, Node.js backend, Python backend, or browser-only WebCrypto API.
- **SHA-256 File Fingerprints**: Live integrity verification before encryption and after decryption.
- **Password Strength Analyzer**: Real-time entropy calculation and visual strength meter (Weak, Fair, Good, Very Strong).
- **Password Generator**: One-click generation of 16-character high-entropy passphrases.
- **Modern Glassmorphism UI**: Dynamic ambient lighting, smooth micro-animations, and drag-and-drop file upload.
- **Dark & Light Mode**: Automatic system preference detection with persistent toggle.
- **Streams up to 100 MB**: Large files stream through temporary files without memory exhaustion.

## 📡 REST API

Both `server.c`, `server.js`, and `server.py` implement identical REST endpoints:

| Method | Path           | Request Body          | Required Header | Description |
|--------|----------------|-----------------------|-----------------|-------------|
| GET    | `/api/health`  | None                  | None            | Health check & backend status |
| POST   | `/api/encrypt` | Raw file binary       | `X-Password`    | Returns encrypted `.enc` binary |
| POST   | `/api/decrypt` | Encrypted file binary | `X-Password`    | Returns restored original binary |

### Command-Line Usage with `curl`:

**Encrypting a file:**
```bash
curl -H "X-Password: my%20password" --data-binary @document.pdf \
     http://127.0.0.1:8080/api/encrypt -o document.pdf.enc
```

**Decrypting a file:**
```bash
curl -H "X-Password: my%20password" --data-binary @document.pdf.enc \
     http://127.0.0.1:8080/api/decrypt -o restored.pdf
```

## 🔒 Encrypted File Format

All engines (C, Node, Python, and WebCrypto) share the exact same binary format:

```
[ 4 Bytes ]   Magic identifier: "FENC" (0x46, 0x45, 0x4E, 0x43)
[ 8 Bytes ]   Cryptographically secure random salt
[ 4 Bytes ]   Big-endian password verification token
[ N Bytes ]   Ciphertext generated by 64-bit xorshift keystream
```

Key derivation uses **100,000 rounds** of salted FNV-1a hashing to protect against brute-force dictionary attacks.
